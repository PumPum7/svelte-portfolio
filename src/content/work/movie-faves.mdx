## Built independently

I designed and built the project end-to-end. The work includes the Flutter interface, navigation, remote data handling, account flow, profile features, and platform setup for iOS and Android.

## System shape

- Typed Dart models and request helpers turn TMDB responses into application data.
- Flutter screens handle releases, discovery, movie details, loading states, and responsive grids.
- GoRouter connects onboarding, authentication, tab navigation, and nested detail routes.
- Firebase provides account and profile services.

## Interface decisions

The home screen separates current cinema and television releases, then uses a sliding panel for trending media. Detail pages keep the score, trailer, overview, and similar titles in one vertical reading flow. The layout uses the same navigation model across the main product screens.

## Reflection

MovieFaves was a focused way to build a complete mobile product around asynchronous data, image-heavy interfaces, nested navigation, and account state. The source remains public as a record of the full implementation.
